🔄 数据更新机制

更新频率
建议每季度（3个月）执行一次全量爬取，每月执行一次增量更新。 抓取时间：GitHub API v4 (GraphQL) + Gitee / GitLab REST API。
增量更新策略
1. 仅更新已收录项目的关注度数值（Star/Fork/Watch）和最后更新时间； 2. 对比各平台 Top 100 榜单，识别新增项目并触发人工审核； 3. 删除连续两个季度未进入 Top 200 的项目。
数据来源：GitHub API、Gitee API、GitLab API、SourceForge API · 综合关注度权重 = Star × 0.6 + Fork × 0.3 + Watch × 0.1
